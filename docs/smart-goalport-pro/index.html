SmartGoalPort - 智能球门计分系统 PRO

项目简介

SmartGoalPort - PRO 是一套专为足球无人机比赛设计的升级版物联网自动化计分系统。系统由多个硬件设备通过 Wi-Fi 自组网构成，实现毫秒级闭环通信，支持自动进球检测、实时比分显示、比赛流程控制等功能。

系统组成

设备 主控芯片 开发框架 功能
接口盒 (中央控制器) ESP32-C6 (ESPC6-32E-N4) ESP-IDF v5.5.4 网络中枢、比分仲裁、全局时钟同步、设备状态管理
球门 ESP32-C3 (ESPC3-12E-N4) PlatformIO + Arduino 激光传感器进球检测、数码管比分显示、RGB 灯效
遥控器 ESP32-C2 (ESPC2-12E-N2) MicroPython 手动比分调控、比赛流程控制
PC 控制台 Windows Python 全屏比分展示、比赛设置、数据管理

通信方式

  • 协议: UDP 广播
  • 端口: 7891
  • WiFi SSID: SmartGoalPort
  • 密码: ocean-monkey
  • 网络拓扑: 星型结构，接口盒（设备码 08）作为中央节点，球门（12/14）、遥控器（20/22）、PC（18）作为终端节点

如何使用各设备运行系统

开机启动顺序

⚠️ 我们程序有强重连机制，一般可任意顺序启动。若设备无法或连接失败请参考一下顺序启动

接口盒操作

操作 功能
双击按键2 进入模式预切换状态， 此时LED开始跑马
预切换时短按按键2 退出预切换模式
预切换时短按按键1 确认切换 WiFi 模式 (STA↔AP)
长按按键1 (>1s) 暂停/继续比赛

球门

  • 上电自动连接 WiFi，此时数码管显示–

  • 连接成功后进入对应灯效，数码管开始转圈直到收到接口盒的数据

  • 比赛进行中: 彩色跑马灯效果

  • 比赛暂停: 彩虹渐变效果

  • WiFi 断开: 白色跑马灯闪烁

  • 激光传感器被遮挡时自动发送进球指令（每秒最多 1 次）

  • 球门可使用备用电源防止突然断电情况发生

遥控器

按键 短按 长按
加分 (ADD) 当前队伍 +1 分 —
减分 (DEC) 当前队伍 -1 分 —
状态 (STATUS) 切换比赛暂停/继续 切换队伍
清除 (CLEAR) — 复位比分
  • 设备码 20 控制 A 队，切换后设备码变更为 22 控制 B 队，反之
  • 电量低时 MULT LED 会闪烁告警

PC 控制台

双击 GoalPort控制台.exe 即可运行，点击连接网络，连接后点击记分面板即可显示比分，可在面板右上角或控制台点击比赛设置管理比赛
