变频器仿真教学系统 - 使用说明

项目简介

本系统是一款专为电气工程专业设计的变频器仿真教学平台，支持教师在线发布作业、管理班级、批改学生作品，同时为学生提供真实的变频器接线与参数设置仿真实验环境。系统采用 Web 技术构建，无需安装任何软件，通过浏览器即可访问使用。

系统架构

系统由三大核心部分组成：

  1. 教师端（管理员后台） - 班级管理、作业发布、成绩评定
  2. 学生端 - 作业接收、考勤签到、仿真练习
  3. 核心仿真引擎 - 变频器仿真、电路连接、三相电系统模拟

一、教师端使用说明

1.1 登录与访问

  1. 打开浏览器，访问系统地址
  2. 使用管理员账号登录（账号信息由系统管理员提供）
  3. 登录后自动进入管理员后台

1.2 班级管理

班级是系统的核心管理单位，所有学生、作业、考勤数据都归属于特定班级。

创建班级

  1. 在右侧班级列表上方点击”新建班级”按钮
  2. 输入班级名称（如：电气0000）
  3. 点击确认，班级创建成功

切换班级

  • 点击右侧班级列表中的班级名称即可切换
  • 当前选中班级会高亮显示

删除班级

  1. 先选中要删除的班级
  2. 点击”删除班级”按钮
  3. 确认删除后，该班级及其所有数据将被清除

1.3 人员管理

点击”人员管理”磁贴进入学生管理界面：

添加学生

  1. 点击”添加学生”按钮
  2. 填写学生信息：
    • 学号：学生的唯一标识，用于登录
    • 姓名：学生姓名
    • 密码：初始登录密码
  3. 点击保存

编辑学生信息

  • 点击学生列表中的”编辑”按钮
  • 可修改学生姓名和密码
  • 学号不可修改

删除学生

  • 点击学生列表中的”删除”按钮
  • 删除后该学生的所有作业记录也将被清除

批量导入学生

  1. 准备 Excel 表格，包含三列：学号、姓名、密码
  2. 点击”导入表格”按钮
  3. 选择 Excel 文件并上传
  4. 系统自动导入所有学生信息

导出学生名单

  • 点击”导出表格”按钮
  • 下载包含班级所有学生信息的 Excel 文件

搜索学生

  • 在搜索框输入学号或姓名
  • 系统实时筛选显示匹配的学生

1.4 作业管理

发布作业

  1. 点击”发布作业”按钮
  2. 填写作业信息：
    • 作业标题：简洁明了的标题
    • 作业描述：详细的要求说明
    • 截止时间：可选，超过截止时间学生将无法提交
    • 满分：默认100分，可根据需要调整
  3. 点击确认发布

查看作业列表

  • 在班级管理页面下方查看所有已发布作业
  • 显示作业标题、截止时间、提交人数等信息

批改作业

  1. 点击作业卡片或”批改”按钮进入批改界面
  2. 查看学生提交列表：
    • 绿色：已提交
    • 灰色：未提交
  3. 点击学生姓名进入评分界面
  4. 在仿真环境中查看学生作品
  5. 输入分数（0-100）和评语
  6. 点击保存评分

删除作业

  1. 点击作业卡片上的”删除”按钮
  2. 确认删除后，该作业及所有提交记录将被清除

1.5 考勤管理

点击”考勤管理”磁贴：

发布考勤

  1. 点击”发布考勤”按钮
  2. 设置考勤标题和截止时间
  3. 发布后学生可在规定时间内签到

查看考勤记录

  • 显示所有考勤活动列表
  • 查看每次考勤的签到情况

删除考勤

  • 点击考勤记录旁的”删除”按钮可删除该次考勤

1.6 成绩占比设置

点击”成绩占比”磁贴：

  • 设置作业成绩在总评中的占比（0-100%）
  • 设置考勤成绩在总评中的占比（0-100%）
  • 两者之和应等于100%
  • 设置后点击保存

1.7 数据导出

点击”数据导出”磁贴：

系统自动生成 Excel 文件，包含两个工作表：

工作表1 - 学生名单

  • 学号、姓名、密码

工作表2 - 成绩汇总

  • 各次作业得分
  • 作业平均分
  • 考勤得分
  • 总评成绩

1.8 进入仿真教学

  • 点击顶部”进入仿真”按钮
  • 在新窗口打开仿真环境
  • 教师可在此进行教学演示或准备作业示例

二、学生端使用说明

2.1 登录

  1. 访问系统登录页面
  2. 输入学号和密码
  3. 点击”登录”按钮

提示：也可以选择”访客进入”体验仿真功能，但访客模式无法接收作业和保存成绩。

2.2 主页功能

登录后进入学生主页，显示四个功能磁贴：

作业详细

  • 查看教师发布的所有作业
  • 查看作业要求、截止时间、得分和评语
  • 点击进入作业仿真环境

考勤签到

  • 查看当前有效的考勤活动
  • 在规定时间内点击签到
  • 查看自己的签到记录

考勤记录

  • 查看历史考勤记录
  • 显示每次考勤的签到状态和时间

进入仿真

  • 直接进入自由仿真模式
  • 可随意练习，不受作业限制
  • 练习结果不会作为作业提交

2.3 作业模式

接收作业

  1. 点击”作业详细”磁贴
  2. 查看作业列表
  3. 点击未完成的作业进入仿真环境

作业仿真界面

  • 左侧工具栏：选择元器件进行接线
  • 中间画布：绘制电路图
  • 右侧作业面板：查看作业要求和提交

完成作业步骤

  1. 从工具栏选择需要的元器件（变频器、电动机、空气开关等）
  2. 在画布上放置元器件
  3. 使用”连线模式”连接各元器件端子
  4. 设置变频器参数（双击变频器打开面板）
  5. 点击”仿真”按钮测试电路
  6. 确认无误后点击”提交作业”

查看成绩

  • 提交后等待教师批改
  • 批改完成后可在作业详情中查看分数和评语（评分后无法修改）

三、核心仿真功能使用说明

3.1 仿真环境概述

仿真环境是系统的核心，提供以下功能：

  • 元器件库：变频器、三相异步电动机、空气开关、电源等
  • 连线系统：可视化拖拽连线
  • 参数设置：完整的变频器参数配置
  • 实时仿真：三相电信号模拟、电机转动动画
  • 安全检测：短路检测、接地检测、断电保护

3.2 基本操作

模式切换

  • 选择模式：选择、移动、删除元器件
  • 连线模式：连接元器件端子

添加元器件

  1. 确保处于”选择模式”
  2. 点击左侧工具栏的元器件按钮
  3. 在画布上点击放置

删除元器件

  1. 右键点击要删除的元器件
  2. 选择”删除”选项

连接导线

  1. 切换到”连线模式”
  2. 点击第一个端子（起点）
  3. 点击第二个端子（终点）
  4. 系统自动创建连线

删除连线

  • 右键点击连线，选择”删除”

3.3 快捷键说明

系统提供丰富的键盘快捷键，提高操作效率。

通用快捷键

快捷键 功能说明 使用条件
X / Delete 删除选中的元器件或导线 选中对象时
B 修改导线颜色 选中导线时
M 移动元器件 选中未连接导线的元器件时
S 标记当前位置 非输入框焦点时
E 打开/关闭查找面板 非输入框焦点时
Q 快速切换仿真模式 非输入框焦点时
Ctrl + Z 撤销上一步操作 非仿真模式时
Ctrl + Y 恢复撤销的操作 非仿真模式时
ESC 关闭弹窗/取消操作/搜索框失焦 任何时候

查找面板快捷键（面板打开时）

快捷键 功能说明
A 切换到上一个标签页（左循环）
D 切换到下一个标签页（右循环）
X 删除标记（在标记标签页时）

仿真模式快捷键

仿真模式下，可使用数字键控制变频器面板：

键盘按键 对应按钮
1 JOG
2 ▲
3 ▼
4 ENT
5 ▷
6 RUN
7 STOP
8 MENU

提示：使用快捷键前，需先选中变频器（点击画布上的变频器）。

3.4 查找与标记功能

查找面板

按 E 键打开查找面板，可查看：

  • A：切换到上一个标签页（左循环）
  • D：切换到下一个标签页（右循环）
  • 说明：作业要求说明
  • 标记：用户添加的位置标记
  • 元器件：当前画布上的所有元器件列表
  • 导线：当前画布上的所有导线列表

添加标记

  1. 将画布移动到需要标记的位置
  2. 按 S 键添加标记
  3. 标记会记录在查找面板的”标记”标签页中
  4. 选择导线、元器件会标记对应的标记项

跳转到标记

  • 在查找面板的”标记”标签页中
  • 点击标记项，画布自动跳转到标记位置

删除标记

  • 鼠标悬停在标记项上，按 X 键删除
  • 或点击标记项旁的删除按钮

3.5 画布操作

移动画布

  • 鼠标中键拖拽：平移画布
  • 按住空格 + 鼠标拖拽：平移画布

缩放画布

  • 鼠标滚轮：放大/缩小画布
  • 缩放以鼠标指针位置为中心

双击操作

  • 双击变频器：打开变频器面板（仿真模式下）

3.6 右键菜单功能

在画布上右键点击可打开快捷菜单：

元器件右键菜单

  • 编辑：编辑元器件属性
  • 删除：删除该元器件

导线右键菜单

  • 改颜色：修改导线显示颜色
  • 删除：删除该导线

空白处右键菜单

  • 粘贴：粘贴剪贴板内容（如有）
  • 取消：关闭菜单

3.7 文件操作

保存工程

  1. 点击菜单栏”文件” → “保存”
  2. 输入文件名
  3. 下载 .vfd 格式的工程文件

导入工程

  1. 点击菜单栏”文件” → “导入”
  2. 选择之前保存的 .vfd 文件
  3. 系统自动加载电路图和参数设置

四、常见问题解答

Q1：无法登录怎么办？

  • 检查学号和密码是否输入正确
  • 确认是否选择了正确的班级
  • 联系教师重置密码

Q2：仿真时电机不转？

  • 检查主回路接线是否正确
  • 检查变频器是否有电源输入
  • 检查参数设置是否正确（P0-02、P0-03）
  • 确认已点击”仿真”按钮

Q3：如何修改已提交的作业？

  • 在截止时间前可重新提交
  • 新的提交会覆盖之前的版本
  • 截止时间后无法修改

Q4：变频器参数设置无效？

  • 确认已进入编程模式（按 MENU 键）
  • 参数修改后需要按 ENT 保存
  • 部分参数需要在停机状态下修改

Q5：连线时提示无法连接？

  • 检查端子类型是否匹配
  • 电源端子只能连接电源端子
  • 控制端子只能连接控制端子
