四触摸双通道PWM调光控制器

2026-05-01 #Touch #PWM #STC8H #交互

四触摸双通道PWM调光控制器

项目概述

本项目基于 STC8H系列单片机，实现了一款4通道触摸输入、2路PWM输出的智能调光控制器。通过4个触摸按键（开关、上调、下调、读取），用户可以灵活控制两路LED灯光的亮度和开关状态，适用于家居照明、氛围灯带、展柜照明等场景。


核心特性

  • 4路电容式触摸输入：提供开关、亮度上调、亮度下调、读取恢复四个功能按键
  • 2路独立PWM输出：可独立控制两路负载的亮度
  • 宽范围无极调光：支持 10% ~ 100% 的亮度调节范围
  • 方向记忆与连续调节：短按切换调光方向，长按实现连续平滑调光
  • 一键全亮恢复：按下”读取”键，两路同时恢复至最大亮度
  • 主开关控制：一键通断，同时控制两路输出的开启与关闭
  • LED状态指示：各按键操作伴有独立的LED指示灯反馈
  • 自动熄灯节能：无操作一段时间后，指示灯自动熄灭

硬件架构

组件 说明
主控芯片 STC8H系列单片机（增强型51内核）
触摸输入 4通道电容式触摸按键
PWM输出 2路PWM信号（频率约4.8kHz），通过P33/P34引脚输出
状态指示 4颗LED指示灯对应各按键状态
工作频率 22.1184MHz

控制逻辑详解

调光基本原理

系统采用PWM（脉冲宽度调制）技术实现调光控制。PWM信号的占空比决定了负载的平均功率，从而控制灯光亮度：

  • 最大亮度：占空比 100%（PWM计数值 2303）
  • 最小亮度：占空比 10%（PWM计数值 230）
  • 调光步进：每次调整减少或增加20个计数值，实现平滑过渡
  • PWM频率：约 4.8kHz，无频闪，适合LED照明

按键功能逻辑

系统包含4个触摸按键，每个按键支持短按和长按两种操作模式：

1. SWITCH（开关键）—— 主控通断

  • 功能：控制系统的总开关状态
  • 短按一次：开启输出（两路恢复至最大亮度）
  • 再次短按：关闭输出（两路亮度归零）
  • 状态保持：再次开启时自动恢复至最大亮度
  • 每次操作伴随指示灯亮起反馈

2. UP（上调键）—— 控制通道A

  • 短按：切换通道A的调光方向（正在变亮则切换为变暗，正在变暗则切换为变亮），实现步进式方向切换
  • 长按（>500ms）：进入连续调光模式，通道A的亮度沿当前方向持续变化，直至达到上限（100%）或下限（10%）自动停止
  • 边界处理：当亮度达到上限时自动切换为减方向，达到下限时自动切换为加方向，确保始终可调

3. DOWN（下调键）—— 控制通道B

  • 短按：切换通道B的调光方向
  • 长按（>500ms）：进入连续调光模式，通道B的亮度沿当前方向持续变化
  • 边界处理：同上，到达边界自动翻转方向

4. READ（读取键）—— 一键恢复

  • 功能：将两路输出同时恢复至最大亮度（100%）
  • 典型场景：用户将亮度调低后需要快速恢复至最亮状态
  • 操作后有指示灯反馈

开关机与状态切换流程

指示灯控制逻辑

  • 操作响应：每次检测到按键操作，对应功能的LED指示灯立即点亮
  • 自动熄灭：无操作超过设定时间后（约1.5秒），所有指示灯自动熄灭，降低功耗
  • 开机提示：系统上电时所有指示灯短暂闪烁，提示系统正常运行

防抖与误触处理

  • 系统采用软件消抖机制，通过10ms的采样间隔对按键状态进行多次确认
  • 采用边沿检测方式（上升沿/下降沿）识别按键动作，避免电平抖动导致的误触发
  • 短按与长按通过计时累加区分，500ms为区分阈值

应用场景

  • 双色温LED灯具：两路分别控制冷白和暖白灯珠，通过亮度比例调节色温
  • 分区照明：两个独立区域的灯光分别控制
  • 氛围灯带：两路RGB灯带的基础亮度控制
  • 展柜照明：独立控制上下两层或左右两个区域的展品照明
