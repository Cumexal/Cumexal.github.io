3D StepMotor Controller — ESP32-S3 步进驱动控制器

基于 ESP32-S3 的三轴步进驱动控制器，支持 Web 页面和 TCP 命令两种控制方式。适用于 3D 打印机、CNC、机械臂等场景。

特性

  • 三轴独立控制 — X/Y/Z 轴，脉冲+方向接口驱动步进驱动器
  • 双控制通道 — Web 页面（浏览器操作）+ TCP 命令（编程/脚本控制）
  • WiFi AP 模式 — ESP32 自建热点，无需路由器，手机/电脑直连
  • 硬件脉冲引擎 — 使用 ESP32 RMT 外设产生精确脉冲，不受主循环干扰
  • 时间估算定位 — 无中断、无 ISR，靠 micros() 时间差估算位置
  • 软限位保护 — 各轴独立可配置的正负软限位
  • 共用使能/报警 — 三轴共用使能信号和报警输入
  • 失能锁止 — 电机失能时所有运动指令被拒绝

硬件接线

电源输入

VCC与GND间最高能承受30V，请注意电压等级，以防损坏设备！

引脚分配

信号 说明
X 轴脉冲 输出脉冲至 X 驱动器
X 轴方向 输出方向电平至 X 驱动器
Y 轴脉冲 输出脉冲至 Y 驱动器
Y 轴方向 输出方向电平至 Y 驱动器
Z 轴脉冲 输出脉冲至 Z 驱动器
Z 轴方向 输出方向电平至 Z 驱动器
使能 三轴共用，低电平使能
报警 三轴共用，低电平报警，内部上拉
警告 LED 启动时/失能时亮橙光
电源 LED 电源正常时亮起不刺眼的绿光

所有输出的IO都是上拉到VCC（24V）的，高电平输出接近VCC，低电平输出接近GND，请注意电压等级，以防损坏连接的设备。

接线端子布局

从接线面从右往左（LED）依次是：

快速开始

1.连接 WiFi

设备 启动后会自动创建名为 StepMotor3D 的 WiFi 热点，密码 12345678。

手机/电脑 → WiFi设置 → 连接 StepMotor3D → 输入密码 12345678

连接成功后，打开浏览器访问：

http://192.168.4.1

即可看到控制页面。

2.Web 控制页面

浏览器打开 http://192.168.4.1 后，页面包含：

位置显示

实时显示 X/Y/Z 三轴当前位置（mm），50ms 刷新一次。

点动控制

按下方向按钮电机持续运动，松开立即停止。支持触摸和鼠标操作。

速度滑条调节点动速率（100~20000 脉冲/秒）。

相对位移

输入各轴移动距离（mm），点击「相对移动」执行。负值反向移动。

功能按钮

  • 回原点 — 三轴回到 0 位
  • 停止 — 紧急停止所有运动
  • 使能 — 电机使能（允许运动）
  • 失能 — 电机失能（禁止运动，LED 亮）

高级配置

点击「高级配置」展开，可调每轴参数：

  • 脉冲数/转（步距角 × 细分数）
  • 脉冲周期 μs（决定最大速度）
  • 丝杠导程 mm/转
  • 正/负软限位 mm

支持「应用到当前轴」或「同步到所有轴」。

3.TCP 命令控制

连接到 设备 的 WiFi 热点后，可用任意 TCP 客户端连接：

目标: 192.168.4.1
端口: 9000

命令格式为纯文本，必须以换行符 \n 结尾。

支持的命令

命令 说明
home 三轴回原点
stop 立即停止所有运动
enable 电机使能
disable 电机失能
x10.5y-9z0 相对位移：X 走 10.5mm，Y 走 -9mm，Z 不动

注意：TCP 命令必须以回车/换行结束，否则不会被解析。

LED 状态指示

LED 状态 含义
常亮 → 熄灭 系统启动中 → 启动完成
点亮 电机处于失能状态
熄灭 电机使能且无报警

软限位说明

当电机使能时，任何会导致超出软限位的移动指令都会被拒绝。限位以 回原点后的绝对位置 计算，建议首次上电后先执行回原点操作。

常见问题

Q: 发送 TCP命令 后 没反应？
A: TCP 命令必须以换行符结尾。确认发送的是 命令\r\n 。另外可能是电机处于失能状态，检查报警指示灯是否有亮。

Q: 失能状态还能移动电机？
A: 失能状态下所有运动指令（点动、相对移动、TCP move、Web 回原点）都会被拒绝。如果还能动请确认固件已更新。

Q: 无法进入网页控制器或无法使用TCP命令？
A: 检查 Web 页面连接状态，确保手机/电脑IP在 AP 网段 (192.168.4.x)，当手机提示此 WIFI 无法连接到互联网时请点击保持连接。

Q: 报警后如何恢复？
A: 报警信号消失后，点击 Web 页面的「使能」按钮或发送 TCP 命令 enable 即可重新使能电机。
