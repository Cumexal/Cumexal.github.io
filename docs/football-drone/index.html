系统概述

本项目是一套专为足球无人机比赛设计的自动化计分系统，由四个核心硬件组件构成：

组件 功能定位 核心职责
接口盒 网络中枢 负责所有设备间的 UDP 通信桥接，全局时钟同步与冲突消解
球门 检测 + 显示 激光传感器检测进球，数码管本地显示比分
遥控器 控制端 手动比分调控、比赛流程控制（启/停/复位）
PC端 控制中心 全屏比分展示、队伍信息编辑、数据库管理

全部设备通过 Wi-Fi 自组网（SSID: SmartGoalpost），100 米内无需额外基站即可实现毫秒级闭环通信。系统采用 “边缘计算 + 集中仲裁” 混合架构：各设备在本地完成关键决策，再由接口盒进行全局时钟同步与冲突消解，确保比赛规则刚性执行。

系统架构

  • Wi-Fi 网络：SSID = SmartGoalpost，密码 = bycumexal
  • 接口盒：工作于 AP 模式（自建热点）或 Station 模式（连接外部路由器）
  • 球门 × 2：工作于 Station 模式，连接到接口盒
  • 遥控器 × 2：工作于 Station 模式，连接到接口盒
  • PC 端：工作于 Station 模式，连接到接口盒

所有设备通过 UDP 协议（端口 8080/8888）在局域网内通信，接口盒作为数据枢纽进行全局时钟同步与冲突消解。

  • AP 模式：接口盒自建 WiFi 热点 SmartGoalpost，所有设备（球门、遥控器、PC）以 Station 模式连接
  • Station 模式：接口盒连接外部路由器/手机热点，所有设备通过路由器组网

硬件模块说明

接口盒

核心芯片：STC8H 系列单片机 + ESP8266 (ESP-01S) WiFi 模块

硬件资源：

  • 1 个按键（模式切换）
  • 1 个蜂鸣器（状态提示）
  • LED 指示灯：WORK（电源/工作）、CONNECT（WiFi 连接状态）、RUN（比赛运行）、SMODE/AMODE（模式指示）
  • EEPROM（断电保存比分和模式配置）

工作模式：

模式 角色 适用场景
AP 模式 自建 WiFi 热点 SmartGoalpost 现场无可用网络，接口盒做主站
Station 模式 连接外部热点 现场有路由器/手机热点，信号更稳定

代码逻辑 ：

  1. 上电后读取 EEPROM 中的模式配置和上次比分
  2. 如果按键按下（ModeKey == 0），强制切换为 AP 模式
  3. 按配置的模式初始化 ESP8266，建立 UDP 通道
  4. 主循环中持续接收 UDP 数据包，按命令处理：
    • TA+/TA-/TB+/TB-：加减 A/B 队比分，写 EEPROM，广播比分到所有设备
    • GS/GA/GR：暂停/开始/复位比赛，同步所有设备
    • GCF：向请求方广播当前比分
    • GI：回复当前比赛状态
  5. 定时查询按键，检测模式切换请求
  6. 连接异常超过 5 次则自动重启

UDP 广播机制：接口盒向预定义的 6 个静态 IP 地址广播数据（192.168.4.12 ~ 192.168.4.22，步长 2），确保所有设备同步。

球门

核心芯片：STC8H 系列单片机 + ESP8266 (ESP-01S) WiFi 模块

我们正在 [PlatformIO + Arduino 版本] 迁移至 ESP8266 (ESP-07S) 直接开发。

硬件资源：

  • 2 组对射式激光传感器（CG1、CG2）
  • 2 位共阳极数码管（7 段，通过 IO 口直接驱动）
  • RGB LED 指示灯（LR、LG、LB）
  • 按键：CF（校准）、Tadd（加分测试）

进球检测机制：

  • 激光传感器识别物体穿越球门
  • 每秒最多记录 1 次进球——防止无人机机身缝隙导致单次进球多次触发
  • 触发后发送 TB+ 命令到接口盒，同时锁定计分使能 1 秒

代码逻辑 (球门主控)：

  1. 上电后驱动 RGB LED 闪烁 3 次（启动自检）
  2. 初始化 ESP8266，以 Station 模式连接 SmartGoalpost
  3. 连接成功后发送 GCF 和 GI 获取初始比分和状态
  4. 主循环中：
    • 扫描激光传感器，检测到遮挡则触发进球（addscore = 1）
    • 发送 TB+ 到接口盒
    • 锁定计分 1 秒（enscore = 0，计时 20 个周期后恢复）
    • 接收接口盒广播的比分数据，更新数码管显示
    • 根据比赛状态控制 RGB LED（绿色=运行，红色=暂停）
  5. 连接异常超过 5 次则自动重启

数码管显示规则：

  • 0~99：实时同步显示
  • ≥100：固定显示 99（硬件限制为两位数）

遥控器

核心芯片：STC8H 系列单片机 + ESP8266 (ESP-01S) WiFi 模块

系统配备 2 个遥控器，每个遥控器可独立控制 A 队或 B 队。

硬件资源：

  • 按键：Tadd（加分）、Tsub（减分）、CF（复位）、ModeKey（暂停/继续）
  • LED 指示灯：WORK、CONNECT、RUN
  • 蜂鸣器（操作反馈）

代码逻辑 (遥控器主控)：

  1. 初始化 GPIO、UART、定时器
  2. 初始化 ESP8266，以 Station 模式连接 SmartGoalpost
  3. 主循环中：
    • 扫描按键状态，检测单击/长按/双击
    • Tadd 短按：当前队伍 +1 分（发送 TA+/TB+）
    • Tsub 短按：当前队伍 -1 分（发送 TA-/TB-）
    • ModeKey 短按：暂停比赛（发送 GS）
    • ModeKey 长按：继续比赛（发送 GA）
    • CF 短按：复位比分（发送 GR）
    • CF 双击：切换控制队伍（A ↔ B）
    • 暂停状态下加分/减分按键被禁用
  4. 每 100ms 检测连接状态，异常超过 5 次自动重启

按键功能一览：

按键 短按 长按 快速双击
+ 当前队伍 +1 分 — —
- 当前队伍 -1 分 — —
暂停 暂停比赛 继续比赛 —
复位 复位比分 — 切换控制队伍

指令集

指令 方向 功能 说明
TA+ 遥控器 → 接口盒 A 队加分 遥控器发出，接口盒仲裁后广播
TB+ 遥控器/球门 → 接口盒 B 队加分 球门激光触发或遥控器手动加分
TA- 遥控器 → 接口盒 A 队减分 遥控器手动减分
TB- 遥控器 → 接口盒 B 队减分 遥控器手动减分
GS 任意 → 接口盒 暂停比赛 暂停后加分/减分被禁用
GA 任意 → 接口盒 开始/继续比赛 恢复计分能力
GR 遥控器 → 接口盒 复位比分 A/B 队比分归零
GCF 任意 → 接口盒 获取当前比分 接口盒回复 TAS<n>TBS<n>
GI 任意 → 接口盒 获取当前状态 接口盒回复 GA 或 GS
UPD 接口盒 → 所有设备 比分已更新 通知各设备重新拉取比分
TASTBS 接口盒 → 所有设备 广播比分 如 TAS10TBS20 表示 A 队 10 分，B 队 20 分
VAS PC → 接口盒 设置 A 队比分 用于 PC 端手动调分
VBS PC → 接口盒 设置 B 队比分 用于 PC 端手动调分

代码结构详解

项目文件树

接口盒代码逻辑

核心职责：比分仲裁、全局状态同步、模式管理

关键机制：

  • 数据持久化：每次比分变化立即写入 EEPROM，断电恢复不丢失
  • 全设备同步：接受到任何设备的比分变更命令后，向 6 个预配 IP 广播完整比分
  • 模式记忆：模式切换后写入 EEPROM，下次启动自动恢复

球门代码逻辑

核心职责：进球检测、本地比分显示

关键机制：

  • 防抖锁定：进球后锁定计分使能 1 秒（enscore = 0，20 个周期 × 50ms），保证单次进球只计 1 分
  • 激光传感器：两组对射式激光实时检测，任何一路被遮挡即触发

遥控器代码逻辑

核心职责：人机交互、命令发送

关键机制：

  • 队伍切换：双击复位键切换控制队伍，通过 mode 变量区分 A/B 队
  • 暂停锁定：暂停状态下加分/减分被禁用（enplay = 0 时忽略加减按键）
  • 操作反馈：每次按键发送成功后蜂鸣器响

开机启动

⚠️ 务必严格按照以下顺序启动，否则可能导致设备无法发现或连接失败。

操作指南

接口盒模式切换

  • 重启后 SMODE 指示灯亮 = AP 模式，AMODE 指示灯亮 = Station 模式

遥控器操作

控制队伍切换：

  • 快速双击「复位」键，切换控制 A 队或 B 队
  • 切换后对应队伍指示灯亮起

比赛控制：

  • 短按「暂停」键 → 暂停比赛（所有设备停止计分）
  • 长按「暂停」键 → 继续比赛
  • 暂停状态下 ± 键被禁用，必须先恢复比赛

比分调整：

  • 按「+」键：当前控制队伍 +1 分
  • 按「-」键：当前控制队伍 -1 分
  • 按「复位」键：所有比分归零

PC 端操作

界面模块：

模块 功能 用途
计分板 全屏显示比分 通过 HDMI 输出至大屏幕/投影仪，供观众观看
设置页面 队伍信息编辑、手动调分、数据库管理 赛前配置或异常时修正

故障排查

现象 可能原因 解决方法
PC 无法连接 WiFi 未启动/模式错误 检查接口盒模式，确认 SmartGoalpost 可见
设备离线 启动顺序错误 按正确顺序重启所有设备
比分不同步 网络延迟/丢包 检查信号强度，必要时重启接口盒
数码管显示 99 分数 ≥ 100 正常现象，或检查 PC 端实际分数
遥控器无反应 处于暂停状态/未切换队伍 长按暂停恢复比赛，或双击复位切换队伍
进球不计分 频率限制/传感器遮挡 确认每秒仅触发一次，检查激光通道是否通畅
设备反复重启 WiFi 连接超时 检查网络信号强度，缩短设备与接口盒的距离

关键限制汇总

限制项 说明
接口盒无互联网 需通过 Station 模式连接外部热点上网
数码管上限 99 超限时固定显示 99
进球检测 1 秒 1 次 防止无人机缝隙导致多次计数
暂停禁调分 必须先恢复比赛才能加减分
