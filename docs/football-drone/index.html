足球无人机计分系统

基于 STC8H 的物联网足球无人机竞技系统
开发平台：STC8 系列增强型 8051 单片机 + ESP8266 WiFi 模块
开发人员：CUMEXAL 、 dokidoki
作者：CUMEXAL

我们正在积极完成从 STC8H 到 ESP8266 的主控升级
以及对PCB、电路设计的优化以降低成本和提高系统的稳定性。

系统概述

本项目是一套专为足球无人机比赛设计的自动化计分系统，由四个核心硬件组件构成：

组件 功能定位 核心职责
接口盒 网络中枢 负责所有设备间的通信桥接，全局时钟同步与冲突消解
球门 检测 + 显示 激光传感器检测进球，数码管本地显示比分
遥控器 控制端 手动比分调控、比赛流程控制（启/停/复位）
PC端 控制中心 全屏比分展示、队伍信息编辑、数据库管理

全部设备通过 Wi-Fi 自组网，100 米内无需额外基站即可实现毫秒级闭环通信。系统采用 “边缘计算 + 集中仲裁” 混合架构：各设备在本地完成关键决策，再由接口盒进行全局时钟同步与冲突消解，确保比赛规则刚性执行。

系统架构

接口盒

核心芯片：STC8H 系列单片机 + ESP8266 (ESP-01S) WiFi 模块

硬件资源：

  • 1 个按键（模式切换）
  • 1 个蜂鸣器（状态提示）
  • LED 指示灯：WORK（电源/工作）、CONNECT（WiFi 连接状态）、RUN（比赛运行）、SMODE/AMODE（模式指示）
  • EEPROM（断电保存比分和模式配置）
  • 掉电自动切换电源电路

工作模式：

模式 角色 适用场景
AP 模式 自建 WiFi 热点 SmartGoalpost 现场无可用网络，接口盒做主站
Station 模式 连接外部热点 现场有路由器/手机热点，信号更稳定

代码逻辑 ：

  1. 上电后读取 EEPROM 中的模式配置和上次比分
  2. 如果上电瞬间按下（多功能按键），强制切换为 AP 模式
  3. 按配置的模式初始化 ESP8266
  4. 主循环中持续接收数据包，按命令处理：
    • 加减 A/B 队比分，写 EEPROM，广播比分到所有设备
    • 暂停/开始/复位比赛，同步所有设备
    • 向请求方广播当前比分
    • 回复当前比赛状态
  5. 定时查询按键，检测模式切换请求
  6. 连接异常超过 5 次则自动重启

球门

核心芯片：STC8H 系列单片机 + ESP8266 (ESP-01S) WiFi 模块

我们正在使用 [PlatformIO + Arduino 版本] 迁移至 ESP8266 (ESP-07S) 直接开发以提高集成度。

硬件资源：

  • 2 组对射式激光传感器（CG1、CG2）
  • 2 位共阳极数码管
  • RGB LED 指示灯
  • 掉电自动切换电源电路

进球检测机制：

  • 激光传感器识别物体穿越球门
  • 每秒最多记录 1 次进球——防止无人机机身缝隙导致单次进球多次触发
  • 触发后发送命令到接口盒，同时锁定计分使能 1 秒

代码逻辑：

  1. 上电后驱动 RGB LED 闪烁 3 次（启动自检）
  2. 初始化 ESP8266，以 Station 模式连接 SmartGoalpost
  3. 连接成功后发送获取初始比分和状态
  4. 主循环中：
    • 扫描激光传感器，检测到遮挡则触发进球
    • 锁定计分 1 秒
    • 接收接口盒广播的比分数据，更新数码管显示
    • 根据比赛状态控制 RGB LED
  5. 连接异常超过 5 次则自动重启

数码管显示规则：

  • 0~99：实时同步显示
  • ≥100：固定显示 99（硬件限制为两位数）

遥控器

核心芯片：STC8H 系列单片机 + ESP8266 (ESP-01S) WiFi 模块

系统配备 2 个遥控器，每个遥控器可独立控制 A 队或 B 队。

硬件资源：

  • 按键：加分按键、减分按键、复位/切换队伍按键（复位）、暂停/继续按键
  • LED 指示灯：WORK、CONNECT、RUN
  • 蜂鸣器（操作反馈）

代码逻辑：

  1. 初始化 GPIO、UART、定时器
  2. 初始化 ESP8266，以 Station 模式连接 SmartGoalpost
  3. 每 100ms 检测连接状态，异常超过 5 次自动重启

按键功能一览：

按键 短按 长按 快速双击
+ 当前队伍 +1 分 — —
- 当前队伍 -1 分 — —
暂停 暂停比赛 继续比赛 —
复位 复位比分 — 切换控制队伍

通信协议

所有设备通过 UDP 协议在 Wi-Fi 局域网内通信。

网络配置

参数 值
SSID SmartGoalpost
密码 bycumexal
UDP 本地端口 8888
UDP 远程端口 8080

网关 192.168.4.1
子网掩码 255.255.255.0

指令集

指令 方向 功能 说明
TA+ 遥控器 → 接口盒 A 队加分 遥控器发出，接口盒仲裁后广播
TB+ 遥控器/球门 → 接口盒 B 队加分 球门激光触发或遥控器手动加分
TA- 遥控器 → 接口盒 A 队减分 遥控器手动减分
TB- 遥控器 → 接口盒 B 队减分 遥控器手动减分
GS 任意 → 接口盒 暂停比赛 暂停后加分/减分被禁用
GA 任意 → 接口盒 开始/继续比赛 恢复计分能力
GR 遥控器 → 接口盒 复位比分 A/B 队比分归零
GCF 任意 → 接口盒 获取当前比分 接口盒回复 TAS<n>TBS<n>
GI 任意 → 接口盒 获取当前状态 接口盒回复 GA 或 GS
UPD 接口盒 → 所有设备 比分已更新 通知各设备重新拉取比分
TASTBS 接口盒 → 所有设备 广播比分 如 TAS10TBS20 表示 A 队 10 分，B 队 20 分
VAS PC → 接口盒 设置 A 队比分 用于 PC 端手动调分
VBS PC → 接口盒 设置 B 队比分 用于 PC 端手动调分

通信流程示例

开机启动

⚠️ 务必严格按照以下顺序启动，否则可能导致设备无法发现或连接失败。

操作指南

接口盒模式切换

  • 重启后 SMODE 指示灯亮 = AP 模式，AMODE 指示灯亮 = Station 模式

遥控器操作

控制队伍切换：

  • 快速双击「复位」键，切换控制 A 队或 B 队
  • 切换后对应队伍指示灯亮起

比赛控制：

  • 短按「暂停」键 → 暂停比赛（所有设备停止计分）
  • 长按「暂停」键 → 继续比赛
  • 暂停状态下 ± 键被禁用，必须先恢复比赛

比分调整：

  • 按「+」键：当前控制队伍 +1 分
  • 按「-」键：当前控制队伍 -1 分
  • 按「复位」键：所有比分归零

PC 端操作

界面模块：

模块 功能 用途
计分板 全屏显示比分 通过 HDMI 输出至大屏幕/投影仪，供观众观看
设置页面 队伍信息编辑、手动调分、数据库管理 赛前配置或异常时修正

故障排查

现象 可能原因 解决方法
PC 无法连接 WiFi 未启动/模式错误 检查接口盒模式，确认 SmartGoalpost 可见
设备离线 启动顺序错误 按正确顺序重启所有设备
比分不同步 网络延迟/丢包 检查信号强度，必要时重启接口盒
数码管显示 99 分数 ≥ 100 正常现象，或检查 PC 端实际分数
遥控器无反应 处于暂停状态/未切换队伍 长按暂停恢复比赛，或双击复位切换队伍
进球不计分 频率限制/传感器遮挡 确认每秒仅触发一次，检查激光通道是否通畅
设备反复重启 WiFi 连接超时 检查网络信号强度，缩短设备与接口盒的距离
设备反复重启 电源不适配 检查电源电压是否在要求范围内，确保正常供电
